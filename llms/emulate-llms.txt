# Emulate, Inc.

> Emulate, Inc. is a Boston, Massachusetts biotechnology company, spun out of Harvard's Wyss Institute in 2014, that commercialized Organ-on-a-Chip technology for human-relevant preclinical research. Its Human Emulation System pairs the Ava Emulation System and Zoe-CM2 Culture Module instruments with Chip-S1, Chip-R1, Chip-A1 and Chip-Array consumables and validated Organ-Chip models for Brain, Liver, Kidney, Lung, Duodenum Intestine, Bone Marrow, Lymphoid and Vagina.

Generated by API Evangelist on 2026-08-01. Emulate does not publish an llms.txt of its own — https://emulatebio.com/llms.txt returned HTTP 404 — so this file is generated from the API Evangelist catalog entry and the artifacts probed from Emulate's public surface.

Important for agents: Emulate publishes **no developer portal, no API reference, no SDKs and no API keys**. The one machine-readable surface found is the anonymous, read-only WordPress REST API behind emulatebio.com. Its "software products" are downloadable desktop analysis calculators and a firmware Utility Hub, not API clients.

## APIs

- [Emulate Content REST API](https://emulatebio.com/wp-json/): Anonymous read-only REST surface with six first-party namespaces — news, blog posts, jobs, gated forms, resource library and Organ-Chip support protocols.
